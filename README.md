# Agent-FSM

基于有限状态机（Finite State Machine）的终端操作 Agent。用户可以在可视化状态设计器中自定义状态机，通过模型驱动 Agent 自动执行终端命令。

## 功能

- **文件资源管理器**（左侧）：与终端当前路径同步，实时显示当前目录的文件和文件夹。
- **状态设计器**（中间）：类似 Unity 状态设计器，用户可以自行添加状态节点（开始/普通/结束）、设置条件和动作（终端命令），通过连线定义状态转移。Agent 模式下高亮当前节点。
- **模型对话**（右侧）：支持 Ask 和 Agent 两种模式切换。开发者监测面板展示所有发送给后端模型服务的请求和响应内容。
- **终端**（底部）：连接本地真实终端（通过 node-pty），支持完整的终端交互。
- **可调整分割线**：所有窗口之间的分割线都可以拖拽调整大小。
- **设置面板**：可配置模型参数，包括 API 地址、模型名称、max_tokens、temperature、top_p、presence_penalty、top_k 等。
- **Agent 执行确认**：Agent 模式下每一步操作都需要用户确认后才执行。

## 环境描述

- **全局环境**：当前路径 + 任务目标
- **局部环境**：当前状态机中的信息 + 下一步可走的路径

## 快速开始

### 安装

```bash
npm install
cd client && npm install
cd ..
```

### 开发模式

```bash
npm run dev
```

这将同时启动后端服务器（端口 3001）和前端开发服务器（端口 3000）。

### 生产模式

```bash
npm run build
npm start
```

构建后访问 `http://localhost:3001`。

## 使用说明

### 状态设计器

1. 在中间画布区域**右键**弹出菜单，添加开始/状态/结束节点
2. **双击**节点编辑名称和动作（终端命令）
3. 从节点底部的连接点**拖拽**到另一个节点顶部创建连线
4. **双击**连线编辑转换条件
5. 按 **Delete** 键删除选中的节点或连线

### Ask 模式

直接与模型对话，获取回答。

### Agent 模式

1. 先在状态设计器中设计好状态机
2. 切换到 Agent 模式
3. 点击「启动 Agent」按钮
4. Agent 会从开始节点出发，根据状态机执行
5. 每步操作需要用户在状态设计器底部确认

### 模型设置

点击右上角 ⚙️ 按钮，可调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| API Base URL | `http://localhost:1234/v1` | 模型服务地址 |
| API Key | `not-needed` | API 密钥 |
| Model | `Qwen3.5-0.8B` | 模型名称 |
| Max Tokens | 1024 | 最大输出 token 数 |
| Temperature | 0.1 | 温度参数 |
| Top P | 1.0 | Top-p 采样 |
| Presence Penalty | 2.0 | 存在惩罚 |
| Top K | 20 | Top-k 采样 |

## 技术栈

- **前端**：React + Vite + React Flow（状态设计器）+ xterm.js（终端）
- **后端**：Express + node-pty（终端）+ WebSocket
- **模型接口**：兼容 OpenAI API 格式
